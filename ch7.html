1) Virtual Machines & Virtualization

VM technology allows multiple virtual machines to run on a single physical machine. A Virtual Machine Monitor (VMM) / Hypervisor sits between the hardware and the guest operating systems (e.g. Linux, NetBSD, Windows) and their applications.

Examples: Xen, VMware, UML, Denali. Performance: para-virtualization (e.g. Xen) is very close to raw physical performance.

Virtualization

  • Virtual workspaces: an abstraction of an execution environment made dynamically available to authorized clients through well-defined protocols, with a resource quota (CPU, memory share) and a software configuration (OS, provided services).
  • Implemented on VMs: an abstraction of a physical host machine; the hypervisor intercepts and emulates VM instructions and allows managing the VMs (VMware, Xen).
  • Provides an infrastructure API: plug-ins to hardware/support structures.
  • Virtualized stack: Hardware → Hypervisor → OS → Apps.

Advantages of virtual machines

  • Run operating systems where the physical hardware is unavailable.
  • Easier to create and back up machines.
  • Software testing with “clean” installs of OS and software.
  • Emulate more machines than are physically available.
  • Timeshare lightly loaded systems on one host.
  • Debug problems (suspend and resume the problem machine).
  • Easy migration of VMs (with or without shutdown).
  • Run legacy systems.

1) الأجهزة الافتراضية والـ Virtualization

تقنية الـ VM تسمح بتشغيل عدة أجهزة افتراضية على جهاز فيزيائي واحد. يقع Virtual Machine Monitor (VMM) / Hypervisor بين العتاد وأنظمة التشغيل الضيفة (مثل Linux وNetBSD وWindows) وتطبيقاتها.

أمثلة: Xen وVMware وUML وDenali. الأداء: الـ para-virtualization (مثل Xen) قريب جداً من أداء العتاد الفيزيائي الخام.

الـ Virtualization

  • Virtual workspaces: تجريد (abstraction) لبيئة تنفيذ تُتاح ديناميكياً للعملاء المصرّح لهم عبر بروتوكولات محددة، مع حصة موارد (CPU وذاكرة) وإعداد برمجي (OS والخدمات المقدمة).
  • تُنفَّذ على الـ VMs: تجريد لجهاز مضيف فيزيائي؛ الـ hypervisor يعترض تعليمات الـ VMs ويحاكيها ويسمح بإدارتها (VMware وXen).
  • توفر infrastructure API: إضافات (plug-ins) للعتاد وهياكل الدعم.
  • الـ stack الافتراضي: العتاد ← Hypervisor ← OS ← التطبيقات.

مزايا الأجهزة الافتراضية

  • تشغيل أنظمة تشغيل حيث العتاد الفيزيائي غير متوفر.
  • أسهل بإنشاء الأجهزة ونسخها احتياطياً.
  • اختبار البرمجيات بتثبيتات "نظيفة" من النظام والبرامج.
  • محاكاة أجهزة أكثر من المتوفرة فيزيائياً.
  • مشاركة الوقت (timeshare) للأنظمة قليلة الحمل على مضيف واحد.
  • تصحيح المشاكل (إيقاف مؤقت واستئناف الجهاز المشكل).
  • سهولة ترحيل الـ VMs (مع إيقاف أو بدونه).
  • تشغيل الأنظمة القديمة (legacy).

2) What is a VPN?

A Virtual Private Network (VPN) is a type of private network that uses public telecommunication, such as the Internet, instead of leased lines to communicate.

VPNs became popular as more employees worked in remote locations.

Private networks vs. VPNs

  • Employees can access the network (intranet) from remote locations.
  • Secured networks.
  • The Internet is used as the backbone for VPNs.
  • Saves cost tremendously by reducing equipment and maintenance costs.
  • Scalability.

How it works (overview)

Two connections

One to the Internet and a second to the VPN.

Datagrams

Contain data, destination and source information.

Firewalls

VPNs allow authorized users to pass through the firewalls.

Protocols

Protocols create the VPN tunnels.

2) ما هي VPN؟

الشبكة الخاصة الافتراضية (VPN) نوع من الشبكات الخاصة يستخدم اتصالات عامة مثل الإنترنت بدل الخطوط المؤجرة (leased lines) للتواصل.

أصبحت الـ VPN شائعة مع زيادة عدد الموظفين الذين يعملون من مواقع بعيدة.

الشبكات الخاصة مقابل VPN

  • يستطيع الموظفون الوصول للشبكة (intranet) من مواقع بعيدة.
  • شبكات آمنة.
  • يُستخدم الإنترنت كـ backbone للـ VPN.
  • توفير كبير بالتكلفة بتقليل المعدات والصيانة.
  • قابلية التوسع.

كيف تعمل (نظرة عامة)

اتصالان

الأول بالإنترنت والثاني بالـ VPN.

Datagrams

تحتوي البيانات ومعلومات الوجهة والمصدر.

Firewalls

الـ VPN تسمح للمستخدمين المصرّح لهم بالمرور عبر الجدران النارية.

البروتوكولات

البروتوكولات تنشئ أنفاق (tunnels) الـ VPN.

3) Four Critical Functions, Encryption & Tunneling

Authentication

Validates that the data was sent from the sender.

Access control

Limits unauthorized users from accessing the network.

Confidentiality

Prevents data from being read or copied while transported.

Data integrity

Ensures the data has not been altered.

Encryption

  • A method of “scrambling” data before transmitting it onto the Internet.
  • Public key encryption technique.
  • Digital signature for authentication.

Tunneling

A virtual point-to-point connection made through a public network. It transports encapsulated datagrams.
  • Data encapsulation: the original datagram is encrypted as an inner datagram, placed in the data area of an outer datagram that has its own header.
  • Two types of end points: Remote Access and Site-to-Site.

3) الوظائف الأربع الحرجة والتشفير والـ Tunneling

Authentication (التوثيق)

التحقق أن البيانات أُرسلت من المرسل الحقيقي.

Access control (التحكم بالوصول)

منع المستخدمين غير المصرّح لهم من الوصول للشبكة.

Confidentiality (السرية)

منع قراءة البيانات أو نسخها أثناء نقلها.

Data integrity (سلامة البيانات)

التأكد أن البيانات لم تتغير.

التشفير (Encryption)

  • طريقة "تشويش" البيانات قبل إرسالها على الإنترنت.
  • تقنية التشفير بالمفتاح العام (public key).
  • التوقيع الرقمي للتوثيق.

الـ Tunneling (النفقنة)

اتصال افتراضي نقطة-لنقطة يتم عبر شبكة عامة. ينقل datagrams مغلّفة (encapsulated).
  • التغليف: الـ datagram الأصلي يُشفَّر كـ datagram داخلي، ويوضع في منطقة بيانات datagram خارجي له header خاص.
  • نوعا نقاط النهاية: Remote Access وSite-to-Site.

4) VPN Protocols

Four protocols are used in VPNs: PPTP, L2TP, IPsec and SOCKS (used less than the others).

ProtocolLayerKey points
PPTP
Point-to-Point Tunneling Protocol		Layer 2Remote access VPN distributed with the Windows product family; an addition to PPP; allows multiple Layer 3 protocols; proprietary authentication and encryption; limited user management and scalability; uses MPPE encryption.
L2TP
Layer 2 Tunneling Protocol		Layer 2Combines and extends PPTP and L2F (Cisco); weak authentication and encryption; an addition to PPP; must be combined with IPsec for enterprise-level security.
IPsec
Internet Protocol Security		Layer 3For remote access, intranet and extranet VPNs; the Internet standard for VPNs; flexible encryption and message authentication/integrity.
SOCKS-Not used as much as the others.

6) Advantages vs. Disadvantages

Advantages: cost savings

  • Eliminates expensive long-distance leased lines.
  • Reduces long-distance telephone charges for remote access.
  • Transfers the support burden to service providers.
  • Lower operational costs.

Advantages: scalability

  • Flexibility of growth.
  • Efficiency with broadband technology.

Disadvantages

  • Requires in-depth understanding of public network security issues and proper precautions.
  • Availability and performance depend on factors largely outside your control.
  • Immature standards.
  • Must accommodate protocols other than IP and existing internal network technology.

6) المزايا مقابل العيوب

المزايا: توفير التكلفة

  • إلغاء الحاجة للخطوط المؤجرة المكلفة بعيدة المدى.
  • تقليل رسوم الاتصال الهاتفي بعيد المدى للوصول عن بُعد.
  • نقل عبء الدعم إلى مزودي الخدمة.
  • تكاليف تشغيلية أقل.

المزايا: قابلية التوسع

  • مرونة في النمو.
  • كفاءة مع تقنية broadband.

العيوب

  • تتطلب فهماً عميقاً لمشاكل أمان الشبكات العامة وتطبيق الاحتياطات المناسبة.
  • التوفر والأداء يعتمدان على عوامل خارج سيطرتك إلى حد كبير.
  • معايير غير ناضجة.
  • يجب أن تستوعب بروتوكولات غير IP وتقنية الشبكة الداخلية الموجودة.

7) Applications & Industries

Site-to-Site VPN

Large-scale encryption between multiple fixed sites such as remote offices and the central office. Traffic is sent over the branch office’s Internet connection, saving hardware and management expenses.

Remote Access VPN

Encrypted connections between mobile/remote users and their corporate networks. The user makes a local call to an ISP instead of a long-distance call to the corporate server. Ideal for telecommuters and mobile sales people; lets them use broadband (DSL, cable).

Industries that may use a VPN

IndustryUse
HealthcareTransfer confidential patient information within medical facilities and providers
ManufacturingLet suppliers view inventory and clients purchase online safely
RetailSecurely transfer sales data or customer info between stores and headquarters
Banking/FinancialTransfer account information safely between departments and branches
General businessSecure communication between remote employees

7) التطبيقات والقطاعات

Site-to-Site VPN

تشفير واسع النطاق بين عدة مواقع ثابتة مثل المكاتب البعيدة والمكتب الرئيسي. تُرسل الحركة عبر اتصال الإنترنت الخاص بالفرع، مما يوفر نفقات العتاد والإدارة.

Remote Access VPN

اتصالات مشفرة بين المستخدمين المتنقلين/البعيدين وشبكات شركاتهم. يجري المستخدم مكالمة محلية لمزود الإنترنت (ISP) بدل مكالمة بعيدة المدى لسيرفر الشركة. مثالي للعاملين عن بُعد ومندوبي المبيعات المتنقلين؛ ويتيح لهم استخدام broadband (DSL، كيبل).
