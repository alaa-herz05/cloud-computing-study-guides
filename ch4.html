1) What is IaaS?

Infrastructure-as-a-Service (IaaS) is a service model that involves outsourcing the basic infrastructure used to support operations, including storage, hardware, servers and networking components. IaaS provides virtualized computing resources over the internet.
  • The service provider owns the infrastructure equipment and is responsible for housing, running and maintaining it.
  • The customer typically pays on a per-use basis.
  • The customer uses their own platform (Windows, Unix) and applications.

Components

Virtual Machines (VMs)

Virtual servers rented from the provider.

Storage

Disks and online storage.

Networking

IPs, firewalls, load balancers, VLANs.
Analogy: think of it as renting IT infrastructure instead of owning it.

The cloud stack: Cloud Clients (browser, mobile app, thin client, terminal emulator) → SaaS (CRM, email, virtual desktop, communication, games) → PaaS (execution runtime, database, web server, development tools) → IaaS (virtual machines, servers, storage, load balancers, network).

1) ما هي IaaS؟

IaaS (البنية التحتية كخدمة) نموذج خدمة يعتمد على إسناد البنية التحتية الأساسية لدعم العمليات (تخزين، أجهزة، سيرفرات، مكونات شبكة) لطرف خارجي. وتوفر موارد حوسبة افتراضية (virtualized) عبر الإنترنت.
  • مزود الخدمة يملك المعدات ومسؤول عن إيوائها وتشغيلها وصيانتها.
  • العميل عادةً يدفع حسب الاستخدام (per-use).
  • العميل يستخدم منصته الخاصة (Windows, Unix) وتطبيقاته.

2) Features, Benefits, Providers & Challenges

Key features

  • Scalability: resources scale up or down on demand.
  • Pay-as-you-go: cost-efficient billing.
  • Self-service: users provision resources on demand.
  • Multi-tenancy: many users share resources securely.

Benefits

  • Cost savings: no on-premises hardware.
  • Flexibility: deploy and test environments rapidly.
  • Reliability: redundant infrastructure ensures uptime.
  • Global reach: access from anywhere with internet.

Challenges

  • Security risks: shared infrastructure may pose vulnerabilities.
  • Cost management: over-provisioning increases expenses.
  • Dependency: risk of vendor lock-in.

Examples of IaaS providers

  • Amazon Web Services (AWS): EC2, S3
  • Microsoft Azure: Virtual Machines
  • Google Cloud Platform (GCP): Compute Engine
  • IBM Cloud: Bare Metal Servers

2) الخصائص والفوائد والمزودون والتحديات

أهم الخصائص

  • Scalability: زيادة/تقليل الموارد حسب الطلب.
  • Pay-as-you-go: فوترة اقتصادية.
  • Self-service: المستخدم يجهز الموارد بنفسه.
  • Multi-tenancy: عدة مستخدمين يتشاركون الموارد بأمان.

الفوائد

  • توفير التكلفة: بدون أجهزة داخلية.
  • المرونة: نشر واختبار البيئات بسرعة.
  • الموثوقية: بنية احتياطية تضمن التشغيل.
  • انتشار عالمي: الوصول من أي مكان بالإنترنت.

التحديات

  • مخاطر أمنية: البنية المشتركة قد تسبب ثغرات.
  • إدارة التكلفة: الإفراط بالحجز يرفع النفقات.
  • الاعتمادية: خطر الارتباط بمزود واحد (vendor lock-in).

أمثلة على مزودي IaaS

  • Amazon Web Services (AWS): EC2 وS3
  • Microsoft Azure: Virtual Machines
  • Google Cloud Platform (GCP): Compute Engine
  • IBM Cloud: Bare Metal Servers

3) Highlights of IaaS

  • On-demand computing resources: eliminates the need for far-ahead planning.
  • No up-front commitment: start small and grow as required; no contract, only a credit card.
  • Pay for what you use.
  • No maintenance.
  • Measured service.
  • Scalability and Reliability.

3) أبرز نقاط IaaS

  • موارد حوسبة عند الطلب: تلغي الحاجة للتخطيط المسبق الطويل.
  • بدون التزام مسبق: ابدأ صغيراً وكبّر حسب الحاجة؛ بدون عقد، فقط بطاقة ائتمان.
  • ادفع مقابل ما تستخدمه فقط.
  • بدون صيانة.
  • خدمة مقاسة (Measured service).
  • قابلية التوسع والموثوقية.

4) What is Amazon EC2?

Amazon Elastic Compute Cloud (EC2) is a web service that provides resizable computing capacity used to build and host different software systems.
  • Designed to make web-scale computing easier for developers.
  • A user can create, launch and terminate server instances as needed, paying by the hour for active servers, hence the term “elastic”.
  • Scalable, pay-as-you-go compute capacity; elastic means it scales in both directions.
  • An EC2 instance looks much like physical hardware, and users control nearly the entire software stack, from the kernel upwards.

4) ما هي Amazon EC2؟

Amazon Elastic Compute Cloud (EC2) خدمة ويب توفر قدرة حوسبة قابلة لتغيير الحجم تُستخدم لبناء واستضافة أنظمة برمجية مختلفة.
  • مصممة لتسهيل الحوسبة بحجم الويب (web-scale) على المطورين.
  • المستخدم يستطيع إنشاء وتشغيل وإنهاء instances حسب الحاجة، ويدفع بالساعة للسيرفرات الفعالة، ومن هنا اسم "elastic".
  • قدرة حوسبة قابلة للتوسع بنظام الدفع حسب الاستخدام؛ المرونة تعني التوسع بالاتجاهين (زيادة ونقصان).
  • الـ instance يشبه الجهاز الفعلي، والمستخدم يتحكم بمعظم الـ software stack من الـ kernel للأعلى.

5) AMI & Instance

An Amazon Machine Image (AMI) is an immutable representation of a set of disks containing an operating system, user applications and/or data. It is a template for software configuration (OS, application server, applications).
  • From one AMI you can launch multiple instances, which are running copies of the AMI.
  • An instance is an AMI running on virtual servers in the cloud.
  • Each instance type offers different compute and memory capabilities (a different operating environment).

Sources of AMIs

  • Amazon publishes many AMIs for public use.
  • Custom AMIs provided by community members.
  • Users can create their own AMI.

5) AMI وInstance

الـ AMI (Amazon Machine Image) تمثيل ثابت (immutable) لمجموعة أقراص تحوي نظام تشغيل وتطبيقات و/أو بيانات. وهو قالب (template) لإعدادات البرمجيات (OS، application server، التطبيقات).
  • من AMI واحد تستطيع تشغيل عدة instances، وهي نسخ شغّالة منه.
  • الـ Instance هو AMI يعمل على سيرفرات افتراضية في السحابة.
  • كل instance type يوفر قدرات معالجة وذاكرة مختلفة (بيئة تشغيل مختلفة).

مصادر الـ AMI

  • أمازون تنشر AMIs كثيرة للاستخدام العام.
  • AMIs مخصصة من أعضاء المجتمع.
  • المستخدم يقدر ينشئ AMI خاص به.

6) Regions & Availability Zones

  • Amazon has data centers in different regions across the globe (e.g. North America, Europe, Asia).
  • An instance can be launched in different regions, chosen for: being closer to specific customers, or to meet legal or other requirements.
  • Prices of EC2 usage vary by region.
  • Each region has a set of Availability Zones; zones are isolated from failures in other zones.
  • Zones in the same region have inexpensive, low-latency connectivity.

6) المناطق ومناطق التوفر (Regions & Zones)

  • لدى أمازون مراكز بيانات في مناطق (regions) مختلفة حول العالم (مثل أمريكا الشمالية وأوروبا وآسيا).
  • يمكن تشغيل instance في أي region حسب الحاجة: أقرب لعملاء معينين أو لتلبية متطلبات قانونية وغيرها.
  • أسعار EC2 تختلف حسب المنطقة.
  • كل region فيه مجموعة Availability Zones؛ وكل zone معزولة عن أعطال الـ zones الأخرى.
  • الاتصال بين zones في نفس الـ region رخيص وبتأخير قليل.

7) Storage

EC2 provides three storage options: Amazon EBS, Amazon S3 and Instance Storage. Amazon SimpleDB is a related data service.

Amazon EBS (Elastic Block Store)

  • Persistent, block-level storage: basically an additional hard disk you attach to an instance.
  • Suited for databases, file systems and raw block-level access.
  • Operations: create, attach, detach, delete.
  • An EBS volume is a read/write disk created from an AMI and mounted by an instance.
  • Snapshots are stored in S3; a new EBS volume can be re-created from a snapshot.

Amazon S3 (Simple Storage Service)

  • A SOA (Service-Oriented Architecture) providing online storage via web services.
  • Read, write and delete permissions on objects.
  • Uses REST and SOAP protocols for messaging.

Amazon SimpleDB

  • Highly available, flexible, scalable non-relational data store that offloads database administration.
  • Automatically creates multiple geographically distributed replicas for availability and durability.
  • Charges only for resources actually consumed.

Instance Store & EBS lifecycle

  • Instance Store: disks on the host computer (ephemeral0 to ephemeral3); data is lost when the instance is terminated.
  • EBS operations: Create, Attach, Detach, Delete.
  • Snapshot flow: EBS volume of Instance A → snapshot stored in S3 → create a new volume → attach to Instance B.

7) التخزين (Storage)

توفر EC2 ثلاثة خيارات تخزين: Amazon EBS وAmazon S3 وInstance Storage. وهناك خدمة Amazon SimpleDB لقواعد البيانات.

Amazon EBS (Elastic Block Store)

  • تخزين دائم (persistent) على مستوى block: ببساطة هارد ديسك إضافي تربطه بالـ instance.
  • مناسب لقواعد البيانات ونظم الملفات والوصول الخام للـ block.
  • العمليات: إنشاء، ربط، فصل، حذف.
  • الـ EBS volume قرص قراءة/كتابة يُنشأ من AMI ويُركَّب على instance.
  • الـ Snapshots تُخزَّن في S3، ويمكن إعادة إنشاء EBS جديد منها.

Amazon S3 (Simple Storage Service)

  • SOA (معمارية موجهة للخدمات) توفر تخزين أونلاين عبر web services.
  • صلاحيات قراءة وكتابة وحذف على objects.
  • تستخدم بروتوكولي REST وSOAP للمراسلة.

Amazon SimpleDB

  • مخزن بيانات غير علائقي عالي التوفر ومرن وقابل للتوسع، يخفف عبء إدارة قواعد البيانات.
  • ينشئ تلقائياً عدة نسخ موزعة جغرافياً للتوفر والمتانة.
  • تدفع فقط مقابل الموارد المستهلكة فعلياً.

Instance Store وعمليات EBS

  • Instance Store: أقراص على الجهاز المضيف (ephemeral0 إلى ephemeral3) وتضيع البيانات عند إنهاء الـ instance.
  • عمليات EBS: Create, Attach, Detach, Delete.
  • مسار الـ Snapshot: EBS لـ Instance A ← snapshot يُخزَّن في S3 ← إنشاء volume جديد ← ربطه بـ Instance B.

8) Networking & Security

  • Instances launch on one of two platforms: EC2-Classic or EC2-VPC.
  • Each instance gets two addresses: a private address and a public IP address.
  • The IP is dynamic: a new one is assigned every time an instance is launched, and a replacement instance has a different public IP.
  • Elastic IP = static IP address for dynamic cloud computing. Remap it to a new instance to mask failure. Separate pools for EC2-Classic and VPC.
  • Security Groups control access to instances.

VPC

Launch AWS resources into a virtual network you define: choose the IP range, create subnets, configure route tables, network gateways and security settings.

Security Group

Specifies the protocols, ports and source IP ranges allowed to reach your instances. Create several groups and assign each instance to a group to determine its traffic.
From the console: Security Group 80_22_open = ports 80 (HTTP) and 22 (SSH) open. Key Pair (e.g. GSG_Keypair) is the key pair used to log in securely to the instance. Each instance gets a private and a public IP.

8) الشبكات والأمان

  • تُشغَّل الـ instances على منصتين: EC2-Classic أو EC2-VPC.
  • كل instance يحصل على عنوانين: عنوان خاص (private) وعنوان IP عام (public).
  • الـ IP ديناميكي: يُعطى عنوان جديد في كل مرة يُشغَّل فيها الـ instance، والـ instance البديل له IP عام مختلف.
  • الـ Elastic IP = عنوان IP ثابت للحوسبة السحابية الديناميكية. يُعاد ربطه بـ instance جديد لإخفاء العطل. مجموعتان منفصلتان لـ Classic وVPC.
  • الـ Security Groups تتحكم بالوصول للـ instances.

VPC

تشغيل موارد AWS داخل شبكة افتراضية تحددها أنت: اختيار نطاق IP، إنشاء subnets، إعداد route tables وnetwork gateways وإعدادات الأمان.

Security Group

تحدد البروتوكولات والمنافذ ونطاقات IP المصدر المسموح لها بالوصول للـ instances. تنشئ عدة مجموعات وتعيّن كل instance لمجموعة لتحديد حركة المرور.
من الـ Console: الـ Security Group 80_22_open = فتح المنفذين 80 (HTTP) و 22 (SSH). الـ Key Pair (مثل GSG_Keypair) زوج مفاتيح للدخول الآمن للـ instance. وكل instance له private IP و public IP.

9) Monitoring, Auto Scaling & Load Balancing

CloudWatch (monitoring)

Monitors statistics of instances and EBS; monitor, manage and publish metrics; configure alarms based on metrics.

Auto Scaling

Automatically scales EC2 capacity up and down based on rules: adds/removes compute resources by demand. Suited for businesses with variable usage.

Elastic Load Balancing

Distributes incoming traffic across multiple instances.

9) المراقبة والتوسع التلقائي وموزع الأحمال

CloudWatch (المراقبة)

يراقب إحصائيات الـ instances والـ EBS؛ يراقب ويدير وينشر metrics؛ ويضبط تنبيهات (alarms) بناءً عليها.

Auto Scaling

يزيد وينقص سعة EC2 تلقائياً حسب قواعد: يضيف/يزيل موارد حسب الطلب. مناسب للأعمال ذات الاستخدام المتغير.

Elastic Load Balancing

يوزع حركة الدخول على عدة instances.
